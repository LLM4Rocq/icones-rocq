{# Collapsible table-of-contents sidebar. Renders the global `toc` tree (built in tools/auditor/toc.py, registered as a Jinja env global) on every page. The tree is identical on all pages; `toc_active` ({tab, kind, id}, computed per page in render._emit) selects the active node and drives the auto-expand of its ancestors. No-JS baseline: collapsing uses native
/, so the sidebar is fully usable without any JavaScript. The `open` attribute is set on the active branch (active tab → active group) so the current page's neighbourhood is expanded on load; everything else is collapsed. static/toc.js only *enhances* (persist open state, scroll active into view); it is not required for correctness. Links: each node.url is site-root-relative (e.g. "paper/entries/x.html"). We prepend `tab_prefix`, which resolves to the site root (out/) from any page depth — so a link from a depth-2 entry page to another tab's entry becomes "../..//entries/.html", matching the page tree. #} {%- macro _active(node, tab) -%} {#- True iff `node` is the page's active node. -#} {{- toc_active and toc_active.tab == tab and toc_active.kind == node.kind and toc_active.id == node.id -}} {%- endmacro -%} {%- macro _contains_active(node, tab) -%} {#- True iff the active entry/group lives somewhere under `node`.
