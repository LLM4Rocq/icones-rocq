{# Collapsible table-of-contents sidebar. Renders the global `toc` tree (built in tools/auditor/toc.py, registered as a Jinja env global) on every page. The tree is identical on all pages; `toc_active` ({tab, kind, id}, computed per page in render._emit) selects the active node and drives the auto-expand of its ancestors. No-JS baseline: collapsing uses native
/, so the sidebar is fully usable without any JavaScript. The `open` attribute is set on the active branch (active tab → active group) so the current page's neighbourhood is expanded on load; everything else is collapsed. static/toc.js only *enhances* (persist open state, scroll active into view); it is not required for correctness. Links: each node.url is site-root-relative (e.g. "paper/entries/x.html"). We prepend `tab_prefix`, which resolves to the site root (out/) from any page depth — so a link from a depth-2 entry page to another tab's entry becomes "../..//entries/.html", matching the page tree. #} {%- macro _kinds_eq(a, b) -%} {#- Kind equivalence: a lone-entry PPL/Examples H3 is one TOC leaf of kind "section", but its standalone page activates kind "entry" with the SAME id — treat section/entry as interchangeable (ids are unique per tab, so no false positives). -#} {{- 'true' if a == b or (a in ('section', 'entry') and b in ('section', 'entry')) else '' -}} {%- endmacro -%} {%- macro _active(node, tab) -%} {#- True iff `node` is the page's active node. -#} {{- toc_active and toc_active.tab == tab and _kinds_eq(toc_active.kind, node.kind)|trim == 'true' and toc_active.id == node.id -}} {%- endmacro -%} {%- macro _contains_active(node, tab) -%} {#- True iff the active entry/group lives somewhere under `node`. Used to auto-open the ancestor branch. Only one level of nesting needs a deep check (group → entries); chapters check their sections' entries too. -#} {%- set ns = namespace(hit=false) -%} {%- for child in node.children -%} {%- if toc_active and toc_active.tab == tab and _kinds_eq(toc_active.kind, child.kind)|trim == 'true' and toc_active.id == child.id -%} {%- set ns.hit = true -%} {%- endif -%} {%- for gchild in child.children -%} {%- if toc_active and toc_active.tab == tab and _kinds_eq(toc_active.kind, gchild.kind)|trim == 'true' and toc_active.id == gchild.id -%} {%- set ns.hit = true -%} {%- endif -%} {%- endfor -%} {%- endfor -%} {{- 'true' if ns.hit else '' -}} {%- endmacro -%} {%- macro toc_group(node, tab) -%} {%- set is_active = (toc_active and toc_active.tab == tab and _kinds_eq(toc_active.kind, node.kind)|trim == 'true' and toc_active.id == node.id) -%} {%- set has_active = _contains_active(node, tab)|trim == 'true' -%}
