Dependency graph

Every documented entry is a node; a directed edge A → B is one of two kinds. A depends edge (solid, dark) is a real Coq proof-level dependency read from the .glob files: A's documented lemma uses an identifier that B documents. A mentions edge (dashed, light) is a doc co-reference: A's statement, prose or snippet text names an identifier B documents (the same relation the snippet linkifier uses). The depends edges are the load-bearing ones. Entries are nested inside their section, sections inside their tab — colour marks the tab, boxes mark the section. Click any node to open its page. Use the controls to filter by tab, change layout, or focus a node's neighbourhood.

  • depends — real Coq proof dependency (from .glob)
  • mentions — doc co-reference (statement / prose / snippet text)
